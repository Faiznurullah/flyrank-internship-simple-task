## Case Study 1 --- HR Management System

### The Problem

The HR team was managing employee-related processes and records across
existing workflows that were difficult to centralize and maintain. As
the amount of data and number of HR modules increased, the workflow
needed a more structured web-based system.

One of the concrete challenges was moving existing records from
spreadsheets into the new platform without losing the information needed
by the HR team.

### What I Did

I helped translate the HR workflow into a web application and worked on
the system as a Software Engineer Intern.

I developed features across the application using **React** for the
client side and **Laravel** for the backend. I also worked with
**MySQL** for data management and Docker-based environments for
development and deployment.

One of the more concrete parts of the work was transforming more than
**1,200 existing Excel records** into the new platform.

I also prepared the **Software Requirements Specification (SRS)** to
document the system requirements and used **User Acceptance Testing
(UAT)** to validate the implementation against the expected workflow.

### What Came of It

More than **1,200 existing records** were transformed into the new
platform, providing the HR workflow with a centralized application
instead of relying on the previous spreadsheet-based process.

During UAT, **64 of 67 test scenarios** were completed. The process also
gave me practical experience translating business requirements into
software, validating requirements with users, and working on a system
that would eventually be handed over to the company's IT team.

## Case Study 2 --- Corporate Learning Platform

### The Problem

The company wanted to improve employee capabilities in line with its
organizational culture. The existing learning process needed a digital
platform that could support company learning activities and make
learning content easier to manage.

The challenge was not only building another website, but translating the
HR team's learning requirements into a workflow that could be used by
employees and managed by the organization.

### What I Did

I helped develop the company's **Corporate Learning / E-Learning
platform** using an iterative Agile approach.

I worked on the application using **React** on the frontend and
**Laravel** on the backend. The platform was designed around the
learning workflow, including course and learning-content management.

I focused on turning the requirements provided by the HR team into
working application features rather than treating the technical
implementation as separate from the business process.

Throughout development, the application was improved iteratively based
on feedback and validation of the implemented features.

### What Came of It

The project produced a web-based learning platform that supports the
company's effort to improve employee capabilities through digital
learning.

For me, the project demonstrated how software development can support an
organizational objective beyond simply delivering technical features. It
also strengthened my experience working iteratively with business
requirements, frontend and backend development, and deployment-oriented
workflows.

## Case Study 3 --- Javanese Script Learning Application

### The Problem

Learning Javanese script can require repeated practice, especially when
learners need to recognize different character forms and apply them
correctly. A conventional learning experience can also make repetitive
character practice less engaging.

The project aimed to make Javanese script learning more interactive
while introducing machine learning into the learning experience.

### What I Did

I worked on a Flutter-based Javanese script learning application that
combines **gamification** with an embedded **TensorFlow Lite CNN model**
for character recognition.

The application was designed to support learning and practice for
Javanese characters, while the machine learning component was integrated
directly into the Flutter application.

I worked with a large character dataset and prepared the model for use
in a mobile application. The project eventually involved approximately
**200,000 character samples**, with an initial dataset preparation
process that produced around **3,000 samples in one day**.

The work required me to think beyond model training itself: the model
also had to be integrated into an application where the prediction could
become part of the actual learning interaction.

### What Came of It

The result was a mobile learning application that combines Javanese
script learning, gamification, and on-device machine learning.

The project gave me practical experience connecting a machine learning
model with a production-oriented mobile application rather than treating
the model as an isolated experiment. It also strengthened my
understanding of the relationship between dataset preparation, model
development, mobile integration, and user interaction.
